### 💼 What I do

At **NBK Egypt** I automate the path from bare VM to running service:

- Provision Linux servers across Nutanix, VMware, KVM and Hyper-V
- Configure Linux and AIX fleets with **Red Hat Ansible Automation Platform** to meet hardening (MBSS) standards
- Build **GitLab CI/CD** pipelines that provision VMs and ship microservice patches to **OpenShift**
- Troubleshoot OpenShift, from Nutanix storage integration to service-mesh traffic monitoring

Before that: Python developer at **Turing** (evaluating and testing AI-generated code), the **ITI** Cloud Architecture track, and a B.Sc. in Computer Engineering from **AAST**.
